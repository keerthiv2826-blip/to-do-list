# To-Do List Web Application

A simple and user-friendly To-Do List web application developed as part of my internship course.

The application allows users to create, manage, search, and organize their daily tasks.

##  Features

- ➕ Add new tasks
- ✅ Mark tasks as completed
- ↩️ Undo completed tasks
- 🗑️ Delete individual tasks
- 🧹 Clear all tasks
- 🔍 Search tasks
- 📋 Filter tasks by:
  - All
  - Active
  - Completed
- ⭐ Set task priority:
  - High
  - Medium
  - Low
- 🕒 Display task creation date and time
- 🔢 Display remaining task count
- 💾 Save tasks using Browser Local Storage
- 📱 Responsive design for different screen sizes

##  Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage
