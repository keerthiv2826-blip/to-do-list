# To-Do List Web Application

A simple and user-friendly To-Do List web application developed as part of my internship course.

The application allows users to create, manage, search, and organize their daily tasks.

##  Features

- ➕ Add new tasks
- ✅ Mark tasks as completed
- ↩️ Undo completed tasks
- 🗑️ Delete individual tasks
- 🧹 Clear all tasks
- 🔍 Search tasks
- 📋 Filter tasks by:
  - All
  - Active
  - Completed
- ⭐ Set task priority:
  - High
  - Medium
  - Low
- 🕒 Display task creation date and time
- 🔢 Display remaining task count
- 💾 Save tasks using Browser Local Storage
- 📱 Responsive design for different screen sizes

##  Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a web browser.
4. You can also use the Live Server extension in VS Code.

## 🖥️ How to Use

1. Enter a task in the task input box.
2. Select a priority: High, Medium, or Low.
3. Click **Add Task**.
4. Mark a task as completed using the checkbox.
5. Use **Undo** to restore a completed task.
6. Use **Delete** to remove a task.
7. Use **Clear All** to remove all tasks.
8. Use the search box to find a task.
9. Use the filters to view All, Active, or Completed tasks.
10. Tasks are saved using Browser Local Storage.
